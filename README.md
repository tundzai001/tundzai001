## Featured project

### [Early Landslide Monitoring & Warning System](https://github.com/tundzai001/land_slide_web)

An IoT monitoring platform that brings field sensors and geospatial operations into one workflow.

- Combines GNSS displacement, rainfall, groundwater, and IMU measurements.
- Streams station telemetry and alerts through MQTT and WebSockets.
- Provides a live map, station and device management, incident workflows, historical analysis, and GNSS adjustment tools.
- Includes interactive 3D terrain visualization for monitoring and simulation workflows.

**Project stack:** Python · FastAPI · SQLAlchemy · JavaScript · Leaflet · Chart.js · Three.js · MQTT · Raspberry Pi
